# 📄 PDF 划词智能翻译阅读器 (AI Selection Translator)

> 🚀 基于大模型 (LLM) 的高精度划词即译 PDF 阅读器。纯前端单页架构，零后端依赖，支持 GitHub Pages 一键免费部署！

---

## ✨ 核心特性

- ⚡ **划词即译**：鼠标划选英文即可秒出纯中文翻译，点击其他区域自动关闭浮窗。
- 🎯 **智能整词吸附**：划选自动扩展对齐到完整单词边界，彻底避免选中半个词。
- 📝 **整句翻译**：中键单击句子任意位置（或 Alt + 单击），直接高亮并翻译整句；浮窗同时显示完整原文，也保留「整句翻译」按钮。
- 💡 **AI 术语解释**：右键单词，或选中多词术语后在选区内右键，用已配置的模型解释定义、当前语境及简短例子。
- 📜 **连续瀑布流翻页**：默认多页垂直连续滚动排版，滚轮一滑到底。
- 🔍 **超清矢量渲染**：默认 270% 高清大字显示，字迹平滑细腻无锯齿。
- 💾 **自动记忆进度**：浏览器 IndexedDB 毫秒级持久化，自动恢复上次阅读文件与页码。
- 🌐 **多大模型支持**：支持 Google Gemini、DeepSeek、OpenAI (ChatGPT)、硅基流动、MiniMax、Ollama 本地大模型。
- 🔒 **隐私安全**：所有 API Key 仅保存在使用者自己的本地浏览器中，绝不上报云端。

## 整句翻译怎么用

1. 打开 PDF，**中键单击句子任意位置**，直接选中并翻译整句，无需先翻译单词。Alt + 单击也是同样的快捷入口。
2. 普通划选或双击仍然翻译单词；也可以点击浮窗中的 **整句翻译**，扩展现有选区到句子边界并切换翻译。
3. 可以复制译文、朗读整句、收藏，或点击 ↗ 在侧边栏查看。

支持同页跨行、多个文本片段、英文与中文句末标点，并处理常见论文缩写、小数和换行断词。选区跨越多个句子时会保留这些句子。跨页选区不启用整句按钮；扫描 PDF 需要先有可选择的文字层。断句基于 PDF 文本顺序与标点，复杂多栏排版、罕见缩写或页面边界处的未完句可能需要手动划选修正。双击继续用于选词，不额外增加隐蔽的点击手势。

## 专有名词怎么查

直接在单词上右键，AI 会用中文说明它是什么、在所在句子中的含义，并给一个简短例子。多词术语（如 Multi-head attention）先划选完整词组，再在高亮区域内右键。右键其他位置会解释该位置的单词，不会误用之前选中的词。

复用原来的提供商、API 地址、模型和 Key，无需额外配置，不调用搜索引擎。支持流式显示、复制、收藏以及侧边栏查看。没有中键或右键的设备，可以用 Alt + 单击翻译整句、浮窗的「解释术语」按钮查看含义。

鼠标快捷操作仅接管 PDF 文字区域：中键的自动滚动在该区域被阻止，右键显示 AI 解释；**Shift + 右键**保留浏览器菜单。工具栏、侧边栏及其他区域保留原生鼠标行为。浏览器扩展、鼠标驱动或系统手势若提前拦截事件，请用浮窗按钮作为替代。AI 解释基于模型知识与选中术语的所在句子，不是联网检索结果。

开发验证：`node --test tests/sentence-selection.test.cjs`；浏览器回归用例见 `tests/browser.cjs`，需安装 Playwright 并通过 `NODE_PATH` 提供模块位置，然后运行 `node tests/browser.cjs`。使用本机 Edge 时可设置 `PLAYWRIGHT_CHANNEL=msedge`。

## 🛠️ GitHub Pages 快速部署步骤

1. 在 GitHub 上新建一个仓库（例如命名为 `pdf-translator`）。
2. 将本目录下的 `index.html`、`sentence-selection.js` 和 `.nojekyll` 上传至该仓库的主分支（`main`）。
3. 点击仓库顶部的 **Settings** -> 左侧导航栏 **Pages**。
4. 在 **Build and deployment** 下的 **Branch** 选择 `main` 分支并点击 **Save**。
5. 等待 1~2 分钟，即可获得你的专属在线网站地址：
   `https://<你的GitHub用户名>.github.io/pdf-translator/`
